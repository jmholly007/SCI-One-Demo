# SCI One — plain HTML, CSS, and JavaScript

## Open the demo

Double-click **SCI-One-Standalone.html** and open it with Edge or Chrome.

That single file contains the entire demo. It needs no Node.js, npm, React, package installation, build command, server, internet connection, or access token.

## Edit the source

The same demo is also provided as three files:

- `index.html` — page shell
- `style.css` — original styling and responsive layouts
- `app.js` — plain browser JavaScript, inline SVG icons, sample data, and interactions

Keep those files together and open `index.html` to use the editable version. The standalone HTML is an alternative; it does not automatically update when these three files change.

## Included behavior

Navigation, capability trays, search, supplier profiles, tool filters, favorites, tool information, documentation popups, compact mode, and separate sample dashboard tabs are included. The supplier search supports Honeywell, BAE Systems, L3Harris, Raytheon, and Boeing.

Favorites and compact mode are saved in browser storage when available. Local-file storage behavior can vary by browser and company settings. The demo still runs if storage is unavailable; preferences then last for the current page session.

All tools, metrics, and supplier information are sample content. This is a visual proof of concept without production authentication, backend services, or live data connections. Organizational browser and file handling policies still apply.

Icons are inline SVG drawings from Lucide, under the ISC license. See ICON-LICENSE.txt; the notice is also embedded in the standalone file.
